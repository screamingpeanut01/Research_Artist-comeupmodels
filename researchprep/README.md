# researchprep — 연구 준비단계 산출물

이 저장소는 아직 **연구 진입 상태가 아니다**(준비단계). 연구를 시작하기 전의 모든 준비단계 산출물은 이 폴더에 모은다.

## 무엇이 여기에 들어가나
- 연구 아이디에이션·문제 정의·범위 설정
- 연구설계 초안 — 대상·표본 프레임·종속변수(성장의 조작화)·방법 후보
- 데이터 접근성 실측 점검 결과 (생성 코드는 루트 `nbs/`에 두고 여기서 링크)
- 문헌 스코핑 — 읽을 문헌 지도·핵심 개념 정리
- 개념·용어 정리, 의사결정 로그

## 연구 진입 시
정식 연구에 들어가면 `CLAUDE.md` §2 「연구 문서 체계」(주차연구정리·현재_연구진행·연구정리_v2·분석 인덱스)로 전환한다. 이 폴더의 산출물 중 살아남는 것은 그때 정본 문서로 이관한다.
